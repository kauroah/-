# Web Crawler Assignment

This project implements a simple web crawler that downloads at least 100 text web pages.

## Features

- Downloads web pages using Python
- Saves each page as a text file
- Keeps HTML markup intact
- Generates an index file mapping page numbers to URLs

## Installation

Install dependencies:

pip install -r requirements.txt

## Run crawler

python crawler.py

## Output

pages/
    1.txt
    2.txt
    ...
    100.txt

index.txt
